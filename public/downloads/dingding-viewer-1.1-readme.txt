丁丁看图 1.1  使用说明
========================================

【打开】
· 双击桌面“丁丁看图”图标启动。
· 点击“打开图片 / PDF”，或把图片 / PDF / 文件夹直接拖进窗口。
· 左侧图库可切换同文件夹内的图片和 PDF。
· 支持 JPG、JPEG、PNG、BMP、GIF、TIFF、ICO、TGA、WebP、PDF。

【查看】
· 滚轮：以鼠标位置为中心缩放。
· 左键单击：下一张图片 / 下一页 PDF / 下一页多页 TIFF。
· 左键拖动：框选区域，松开后放大选区。
· 中键单击：全屏 / 退出全屏。
· 中键按住拖动：平移大图。
· 0：适应窗口；1：100%；+ / -：放大 / 缩小。
· ↑ / ↓：放大 / 缩小；← / →：切换图片。
· R：旋转；H：水平翻转；F11：全屏。
· F5：幻灯片播放；Esc：退出全屏 / 停止播放。
· PDF 和多页 TIFF 使用 PageUp / PageDown 翻页。
· Ctrl+B：显示 / 隐藏左侧图库；I：显示 / 隐藏右侧信息栏。

【PDF】
· 左侧显示页面缩略图，底栏可输入页码、适宽、整页显示。
· 更多菜单可把全部 PDF 页面导出为 PNG。
· 专业版可合并多个 PDF，或按页 / 每 N 页 / 页码范围拆分。
· PDF 由 Windows 内置引擎在本地渲染。

【专业版】
· 多页 TIFF：左侧页面缩略图，支持翻页。
· 批量重命名：模板 {name} / {num} / {date} / {ext}，预览、冲突检查、撤销。
· 批量水印：文字或 Logo、九宫格位置、透明度、平铺、PNG/JPEG 输出。
· PDF 合并 / 拆分。
· 购买方式：更多菜单 → 升级专业版 → 购买 / 咨询，扫码加微信或付款。
· 把窗口中的机器码和付款截图发给销售方，收到激活码后粘贴激活。
· 二维码缺失时，可先通过窗口里的邮箱或网站联系。

【实用功能】
· 右侧信息面板：尺寸、格式、大小、DPI、EXIF。
· 图片上右键：打开文件、转换、批量转换、批量重命名、批量水印、PDF 工具等。
· 设为壁纸、转换格式、打印、复制图片、重命名、移到回收站。
· 更多菜单 → 批量转换图片，可输出 PNG / JPEG / BMP / TIFF / TGA。
· 窗口大小、最近打开记录会自动保存。

【设为默认看图程序】
Windows 10/11 不允许程序静默修改默认关联，需要手动确认一次：
1. 打开“设置 → 应用 → 默认应用”。
2. 找到“丁丁看图”，为 JPG、PNG、TGA、PDF 等格式选择它。
或者：
右键图片 → 打开方式 → 选择其他应用 → 丁丁看图 → 始终使用。

【程序位置】
%LOCALAPPDATA%\AuroraView\丁丁看图.exe

如果桌面图标被误删，可在程序“更多”菜单中选择“创建桌面图标”。
